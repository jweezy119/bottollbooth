🎯 Session Probe (Headless & Sensor Detection)
Server logs can't see everything. Embed a tiny probe.js in a page and it reports client-side signals — navigator.webdriver, software (SwiftShader) WebGL renderer, plugin count, and sensor APIs — so headless shells and virtualised scrapers get flagged that a UA-only scan would miss.
Signals this browser reports
Integrate — 4 lines
<script src="https://your-api/probe.js"></script>
<script>
  const s = BotTollboothProbe.collect();
  fetch('/api/v1/probe', { method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ namespace:'mysite.com',
      userAgent: navigator.userAgent, signals: s }) });
</script>
Probe signals feed the same classifier as UA signatures — see probe:webdriver / probe:softwareRenderer in the engine.
